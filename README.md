# One-Line Skip Meeting

A single razor-sharp excuse for skipping a pointless meeting, entered in [The Funniest Excuse for Skipping a Meeting](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) on make.fun.

Running `main.py` writes the excuse to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`).
